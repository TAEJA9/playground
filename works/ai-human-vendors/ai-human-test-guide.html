도입 검토에서 추린 후보 업체의 한국어 립싱크 품질을 직접 확인하기 위한 절차다. 무료 범위 안에서, 별도 개발 없이 진행하는 것을 전제로 한다.

00 · Setup

시작 전에

준비물은 음성 파일 4개와 무료 계정뿐이다.

결론부터 — 무료로 지금 당장 되는 곳은 두 곳이다. 후보 4곳 중 Anam과 Simli는 무료 계정을 만들면 바로 음성을 넣어 볼 수 있다. Beyond Presence는 별도 파이프라인을 세워야 하고, 클레온은 SDK 키를 영업 통해 받아야 한다. 따라서 오늘은 두 곳을 돌리고, 나머지 둘은 문의만 넣어두면 된다.
후보무료 범위오늘 가능한가
Anam약 30분바로 가능 외부 음성 입력 방식이 가장 단순하다
Simli약 50분바로 가능 Anam과 음성 형식이 같아 파일을 그대로 재사용한다
Beyond Presence약 40분나중 LiveKit·Pipecat 파이프라인을 세워야 해서 개발이 필요하다
클레온—문의 먼저 SDK 키 발급이 선행. 오늘 문의만 넣어둔다

음성 파일 만들기

지금 쓰는 강사 목소리가 그대로 붙는지를 보는 것이므로, 기존 ElevenLabs 강사 voice와 설정을 그대로 사용한다. 새로 만들거나 기본 음성을 쓰면 실측의 의미가 없다.

두 곳 모두 PCM 16bit · 16kHz · 모노를 요구한다. 형식이 다르면 립싱크가 어긋나므로 변환은 건너뛰지 않는다. ElevenLabs에서 받은 mp3를 아래 명령으로 한 번에 바꾼다.

단계내용
1ElevenLabs에서 강사 voice로 아래 문장 4개를 각각 생성해 mp3로 받는다
2형식 변환 — ffmpeg -i 파일.mp3 -f s16le -acodec pcm_s16le -ar 16000 -ac 1 파일.raw
3네 곳에 같은 파일을 넣는다. 업체마다 다른 음성을 쓰면 무엇 때문에 품질이 갈렸는지 알 수 없다
01 · Input

넣어 볼 문장 4개

실제 수업 스크립트에서 뽑는다. 업체마다 유리한 문장을 고르면 결과가 뒤집힌다.

문장왜 이걸 보는가
① 한국어 설명 + 짧은 반응
"자, 이 문제 같이 볼까요? … 네, 좋아요."		기준선. 여기서 어색하면 나머지는 볼 필요가 없다. "네", "좋아요" 같은 짧은 말에서 입이 아예 안 열리는 경우가 있어 함께 넣는다
② 한국어 + 영어 섞인 문장
"이 문장에서 answer the phone이 정답이에요"		가장 중요하다. 토익 수업은 한 문장 안에서 언어가 바뀐다. 한국어 기준으로 만들어진 립싱크가 영어 부분에서 어긋나는지 본다
③ 숫자와 보기
"3번 문제, 보기 A, B, C, D 중에서"		수업에서 가장 자주 나오는 말인데 짧고 발음이 튀어서 잘 깨진다
④ 30초 이상 긴 설명시간이 갈수록 입이 소리보다 점점 밀리는지. 짧은 문장만 보면 못 잡는다
02 · Check

볼 것 5개

장비도 계측도 필요 없다. 화면 녹화 후 느리게 돌려 보면서 O/X로 적는다.

항목보는 방법X 판정
입과 소리가 맞나재생 속도를 0.25배로 낮춰서 본다. 보통 속도로는 어지간한 오차가 안 보인다입이 소리보다 눈에 띄게 늦거나 빠름
영어에서 무너지나②를 ①과 나란히 놓고 비교영어 구간만 유독 어색함
끊기나④를 끝까지 재생화면이 멈추거나 건너뜀
말 끝난 뒤가 자연스럽나발화가 끝나고 대기 상태로 돌아가는 순간화면이 툭 튐
얼굴이 뭉개지나일시정지해서 입 주변을 본다치아·입술 경계가 뭉개짐

화면 녹화는 윈도우 기본 기능(Win + Alt + R)으로 충분하다. 소리까지 같이 녹화되어야 나중에 느리게 돌려 볼 수 있다.

더 정확히 보고 싶을 때만. 문장 앞에 "빠!" 같은 소리를 붙여 두면 입이 닫혔다 터지는 순간이 뚜렷해서 어긋남을 정확히 찍을 수 있다. 필수는 아니고, 두 업체가 비슷해서 우열을 못 가릴 때 쓰면 된다.
03 · Run

업체별 시작 방법

아바타는 각 사 기본 제공(스톡)으로 한다. 강사 얼굴은 초상권 계약 전이라 쓰지 않는다.

업체절차주의
Anam 무료 가입 → 세션 만들 때 enableAudioPassthrough 를 켠다 → 음성 파일을 넣는다. 공식 예제에 ElevenLabs 연동까지 나와 있다 이 옵션을 안 켜면 외부 음성을 아예 받지 않는다
Simli 무료 가입 → 같은 파일을 그대로 넣는다. 형식 문서 Anam과 형식이 같아 파일을 다시 만들 필요가 없다
Beyond Presence LiveKit 또는 Pipecat을 세운 뒤 연결한다 앞 두 곳과 달리 개발이 필요하다. 앞 두 곳 결과를 본 뒤에 판단해도 늦지 않다
클레온 SDK 키를 요청한다. 함께 물어볼 것 — ① 내장 대화 기능을 안 쓸 때 요금이 내려가는지 ② 넣을 음성의 형식 ③ 강사 아바타 제작 조건 회신이 오면 그때 같은 파일로 동일하게 진행한다
04 · Decide

판정

업체명을 가리고 3명이 본다. 녹화한 영상에서 업체 이름을 지우고 나란히 놓은 뒤, 각자 순위를 매긴다. 립싱크는 학생이 어색하다고 느끼는지가 전부이므로, 수치보다 여러 사람 눈이 정확하다.

통과 기준

  • ①에서 어색하지 않을 것
  • ②에서 영어 구간만 무너지지 않을 것
  • ④에서 끊기지 않을 것

다음 단계

  • 통과한 곳만 비용을 다시 계산한다
  • 그 다음 실제 수업 화면에 붙여 본다
  • 여기까지 통과해야 강사 초상권 계약을 논의한다

※ 이 단계에서 확인하는 것은 립싱크 품질 하나뿐이다. 비용·계약·개인정보 처리는 통과한 업체에 대해서만 따진다. 한 번에 다 보려 하면 진행이 멈춘다.
