DeepBrain 딥브레인 영상 동작이 매번 똑같음여러 번 생성해도 모든 영상에서 휴먼의 움직임이 동일 — 다양성이 없음

ElevenLabs 영상 생성Seedance 2.0 · Veo 3.1 · Gemini Omni 사진 인물 일관성 부족 · 생성 실패자체 생성이 아니라 외부 모델을 골라 불러오는 구조라 사람이 달라지거나, 아예 생성되지 않는 경우도 있었음
정리 — 사진이냐 영상이냐로 실패 방식이 갈림 사진 기반(Higgsfield · Gemini Omni · ElevenLabs)은 공통으로 같은 강사로 여러 번 만들면 다른 사람이 나옴 — 인물 일관성에서 탈락. 영상 기반(딥브레인)은 인물은 일정하나 동작이 고정 — 다양성에서 걸림. HeyGen은 사진 기반이 같은 문제였고, 영상 기반은 본인확인 때문에 시도 자체를 못 함.
즉 두 조건을 동시에 만족한 곳이 아직 없음. 현재로선 딥브레인이 가장 가까우며, 남는 문제는 동작 다양성 하나임.

※ 립싱크 열이 이 표의 핵심인데 5곳이 비어 있음. 실측한 3곳은 모두 기준 미달이었고, 영상 기반 클로닝은 아직 한 곳도 확인하지 못함 — HeyGen은 영상 학습에 본인확인이 걸려 있어 테스트 계정으로는 진행이 막힘. LLM 제어는 거의 전부 ◎ 라 업체를 가르는 기준이 되지 못함 — 실제 변별점은 립싱크 품질과 클로닝 입력 둘뿐. 그리고 이 표의 ◎ 는 품질 보증이 아니라 스펙 충족 표시임 — 실측에서 떨어진 Anam · Simli 도 외부 음성 ◎ · LLM 제어 ◎ 로 서류상 만점이었음. 조건표 통과와 한국어 립싱크 품질 사이에 상관관계가 있다는 근거는 아직 없음. 딥브레인은 실시간 SDK로 외부 음성을 넣을 수 없음이 확인됨 — AIPlayer.send() 는 텍스트만 받고, setCustomVoice() 는 딥브레인 플랫폼에 등록된 음성을 고르는 기능이라 강사 클론 음성을 못 씀. 단 이는 실시간 기능이 없다는 뜻이 아님 — 실시간 SDK도 Custom HTTP LLM 연결도 있음. 걸리는 건 음성 층을 우리가 못 쥔다는 것 하나이며, ElevenLabs 음성을 그대로 가져오는 경로는 공개 문서상 없음 — 딥브레인 × ElevenLabs 제휴(2025.7)는 실재하나 영상 제작(AI Studios) 쪽 플랫폼 통합이고, 우리 계정 · API 키 · 보이스 ID를 붙이는 방식이라는 근거는 어디에도 없음. 다만 Voice Clone API(POST /api/odin/v3/avatars/voiceclone)가 오디오 URL을 받아 voiceId 를 돌려주므로, 강사 음성 샘플을 딥브레인 쪽에 다시 클로닝해 등록하는 경로는 있음. 남은 질문은 그 voiceId 가 실시간 SDK의 findCustomVoice(voiceId) 에 잡히느냐 하나 — 공개 문서로는 확인 불가, 영업 문의 항목. ※ 참고로 HeyGen 은 3rd-party voice 를 정식 지원 — ElevenLabs API 키를 붙여 자기 보이스를 가져오는 절차가 헬프센터에 문서화돼 있음. 음성 층을 누가 쥐느냐에서 두 곳이 갈림. 다만 이는 실시간 제품 기준이며 영상 제작 제품(AI Studios)은 별개라, 영상 제작용 후보 지위는 유지됨. 단가도 8곳 중 3곳(클레온 · D-ID · 딥브레인)이 비공개라 비용 비교가 완결되지 않음. 표의 단가는 실시간 분당 기준이며, 영상 제작은 건당·크레딧 과금이라 과금 체계가 다름 — HeyGen 외에는 공개 자료 없음.

05 · PRIORITY

실존 강사 재현 기준 우선순위

앞 표를 종합한 결과. 실제 강사를 영상으로 학습시킬 수 있고 동시에 외부 LLM을 연결할 수 있는 곳을 위로 뒀음. 비용이 아니라 재현 품질을 기준으로 삼았을 때의 순서.

공개 문서만 보고 매긴 순위 — 실측 결과와는 별개 1순위 세 곳은 영상 클로닝 실측 미실시라 순위가 높다고 검증된 것이 아님. HeyGen은 시도했으나 영상 학습이 본인확인에 막혔고, 우회로 해본 사진 기반은 포즈가 고정이었음.
다만 본인확인은 HeyGen 만의 벽이 아님 — Beyond Presence 도 "explicit consent from the person being replicated · we verify consent during our review process", Tavus 도 본인 동의를 요구함. 실존 인물 영상을 학습시키는 곳은 사실상 전부 동의 절차가 있음. 즉 이건 업체를 가르는 기준이 아니라 영상 클로닝 노선 전체의 전제조건이며, 강사 동의를 확보하지 못하면 1순위 세 곳이 동시에 막힌다. 반대로 3순위 Anam · Simli는 실측했고 한국어 립싱크가 기준 미달이었음. 즉 지금 순위와 실제 품질은 아직 서로 확인되지 않은 상태.
