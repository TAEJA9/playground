02 · VENDOR

업체 종합 비교

STT · TTS · LLM 은 YBM 이 가져가는 층이므로 업체 비교 항목이 아님. 업체가 실제로 파는 것 기준으로 네 가지를 비교.

업체 외부 음성 입력강사 클론 음성 사용 LLM 제어System Prompt · 외부 LLM 연결 클로닝 입력실존 강사 재현 한국어 립싱크핵심 판단 기준 분당 단가실시간 기준
Simli ◎ ◎OpenAI-compatible 사진 1장 실측 — 미달3곳 중 품질 최하 $0.01~0.05최저
Anam ◎오디오 패스스루 ◎Custom LLM 사진 1장 실측 — 미달 $0.11~0.16
Klleon 클레온 ◎startAudioEcho △공개 문서 확인 부족 확인 필요 실측 — 미달 비공개영업 문의
Beyond Presence ◎Speech-to-Video ◎OpenAI-compatible 영상 2~5분 미확인 €0.0875
HeyGen LiveAvatar ◎LITE Mode ◎FULL 에서도 가능 영상 2분 또는 사진 1장 미확인 $0.095영상 제작은 $29/월~
Tavus ◎Echo Mode ◎Persona system prompt 영상 1.5~2분 미확인 $0.32최고
D-ID ○외부 Agent 연동 ◎Custom LLM 사진 또는 영상 미확인 비공개
DeepBrain 딥브레인 ✕실시간 SDK는 텍스트만 입력 ◎Custom HTTP LLM 영상 미확인 비공개

※ 립싱크 열이 이 표의 핵심인데 5곳이 비어 있음. 실측한 3곳은 모두 기준 미달이었고, 영상 기반 클로닝을 지원하는 곳은 하나도 확인하지 못함. LLM 제어는 거의 전부 ◎ 라 업체를 가르는 기준이 되지 못함 — 실제 변별점은 립싱크 품질과 클로닝 입력 둘뿐. 딥브레인은 실시간 SDK로 외부 음성을 넣을 수 없음이 확인됨 — AIPlayer.send() 는 텍스트만 받고, setCustomVoice() 는 딥브레인 플랫폼에 등록된 음성을 고르는 기능이라 강사 클론 음성을 못 씀. 다만 이는 실시간 제품 기준이며 영상 제작 제품(AI Studios)은 별개라, 영상 제작용 후보 지위는 유지됨. 단가도 8곳 중 3곳(클레온 · D-ID · 딥브레인)이 비공개라 비용 비교가 완결되지 않음. 표의 단가는 실시간 분당 기준이며, 영상 제작은 건당·크레딧 과금이라 과금 체계가 다름 — HeyGen 외에는 공개 자료 없음.

03 · PRIORITY

실존 강사 재현 기준 우선순위

앞 표를 종합한 결과. 실제 강사를 영상으로 학습시킬 수 있고 동시에 외부 LLM을 연결할 수 있는 곳을 위로 뒀음. 비용이 아니라 재현 품질을 기준으로 삼았을 때의 순서.

공개 문서만 보고 매긴 순위 — 실측 결과와는 별개 1순위 세 곳은 실측 미실시라 순위가 높다고 검증된 것이 아님. 반대로 3순위 Anam · Simli는 실측했고 한국어 립싱크가 기준 미달이었음. 즉 지금 순위와 실제 품질은 아직 서로 확인되지 않은 상태.
우선후보이유
1순위HeyGen LiveAvatar영상 기반 실제 인물 + LITE로 LLM 완전 분리 가능
1순위Tavus영상 Replica 품질 + Persona/System Prompt + Custom LLM + Echo Mode
1순위Beyond Presence영상 Custom Avatar + Speech-to-Video로 AI stack 완전 분리
2순위DeepBrain 딥브레인영상 Custom Avatar + Voice Clone + 한국어 + Custom HTTP LLM
2순위D-ID영상 · 사진 모두 지원 + Custom LLM
3순위AnamLLM 통제는 매우 좋으나 사람 아바타는 사진 1장 방식
3순위SimliLLM · 아바타 분리는 매우 좋으나 사람 아바타 생성은 사진 기반
확인 필요Klleon 클레온공개 문서만으로 Custom LLM 및 실제 인물 생성 방식 확인 부족

※ 이 순위는 재현 품질 기준이므로 결론의 용도별 구분과는 층위가 다름. 3순위인 Anam · Simli도 실시간 휴먼용으로는 여전히 유효하며, 사진 1장으로 즉시 착수할 수 있다는 점이 오히려 강점. 비용을 우선하면 순서가 뒤집힘.
