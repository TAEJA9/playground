필요한 기능

  • ①휴먼의 음성 — 강사 클론 음성(ElevenLabs)을 그대로 넣을 수 있어야 함
  • ②LLM 별도 연결 — 수업 스캐폴딩 로직에 따라 반영이 되어야 함

  • ⑤한·영 혼용
  • ⑥끼어들기 — 사용자가 끼어들었을 때와 아닐 때를 적절히 구분
  • ⑦상호작용 — 1회성이 아니라 수업 내내 실시간 대화가 가능해야 함
  • ⑧안정성 — 30초 이상 연속 발화 시 일관성이 유지되어야 하고, 음질이 깨지지 않아야 함

개발사에 확인 요청할 항목

  • 딥브레인 — Voice Clone API 로 만든 voiceId 를 AI Human 실시간 SDK 에서 쓸 수 있는가. 되면 실시간 후보로 복귀, 안 되면 영상 제작 전용
  • Beyond Presence — 한국어를 지원하는가(공개 언어 목록에 없음) · 커스텀 아바타 심사 소요 기간 · 오디오 입력 포맷
  • HeyGen — 영상 클로닝 본인확인 절차의 구체적 요건(강사 본인이 무엇을 해야 하는가)
  • 클레온 · D-ID · 딥브레인 — 단가(3곳 모두 비공개)
  • 공통 — 한·영 혼용 발화 시 립싱크 · 끼어들기(barge-in) 처리 · 30초 이상 연속 발화의 드리프트
